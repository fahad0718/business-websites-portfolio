# Business Websites Portfolio

A portfolio repository for polished websites and digital experiences for small businesses.

## Demo 01 — Noir & Bean

A fictional premium café website demonstrating responsive design, conversion-focused calls to action, business information, menu presentation, and deployment-ready HTML/CSS/JavaScript.

### Purpose

This demo can be adapted for cafés, restaurants, salons, coaches, local shops, freelancers, and other small businesses.

### Run locally

Open `index.html` in a browser, or use the VS Code Live Server extension.

### Status

Demo v1 — portfolio foundation.
